# Haydar — Personal Portfolio

> A personal portfolio website showcasing my work across **software development, AI/ML, and visual design**.

🌐 **Live Website:** [haydar-portfolio.vercel.app](https://haydar-portfolio.vercel.app/)

---

## Overview

This repository contains the source code for my personal portfolio website. The portfolio was created to present selected projects, technical skills, design work, and professional background as an Informatics graduate.

The website brings together my interests in **software development, artificial intelligence/machine learning, and visual design** into a single digital portfolio.

---

## ✨ Features

* Responsive portfolio website
* Personal introduction and professional profile
* Technical project showcase
* Graphic design portfolio
* Project filtering by design category
* Skills and technology showcase
* Links to GitHub repositories and external project resources
* Contact and social media links
* Responsive layout for desktop and mobile devices

---

## 🛠️ Tech Stack

* **HTML5** — Website structure
* **CSS3** — Styling, layout, and responsive design
* **JavaScript** — Interactions and dynamic content
* **Vercel** — Deployment and hosting

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/darhay/portofolio.git
```

Navigate to the project directory:

```bash
cd portofolio
```

Then open `index.html` in your browser.

For the best development experience, use a local development server such as **VS Code Live Server**.
